## What Tempo is

A pnpm monorepo (Node >= 22, `packageManager: pnpm@11.7.0`, ESM everywhere):

- `apps/api` — Fastify API. Central error handler in `apps/api/src/app.ts`.
- `apps/web` — Next.js 16 briefing viewer (client-side Supabase auth).
- `apps/mobile` — Expo/React Native app (expo-router). Screens under
  `apps/mobile/src/features/`.
- `apps/ingestion`, `apps/intelligence`, `apps/generation`, `apps/delivery` —
  one-shot runners coordinated by Postgres leases + idempotency keys.
- `apps/test-env` — bootstrap/reset/smoke tooling for the shared test env.
- `packages/contracts` (zod schemas), `packages/database` (repositories +
  migrations), `packages/delivery` (Expo/Resend/Twilio providers),
  `packages/domain`.

Quality gate: `pnpm check` = prettier + eslint (`--max-warnings 0`) + tsc +
vitest. CI on every PR runs two checks: **Verify** and **Build service image**.
Both must be green before merge; Render deploys `main` only after checks pass.
